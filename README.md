# JsThings

An incomplete & unmaintained typescript/angular based 2D game engine from 2018. The code in this repo is an example of how not to make a videogame.

Angular 5 application implementing a 2D side-scrolling platform game with QuadTree collision detection, and canvas-based rendering. 

## Legacy code security warning
This code is unmaintained since 2018. It has some very old dependencies:

- Node 8.9 (EOL since 2019)
- The Angular version is 5.2.0 (13 major versions behind)
- Typescript version is 2.5 (4 major versions behind)

It has a lot of security issues. Don't attempt to build and run it.
